# Hierarquia de Títulos

HTML possui **6 níveis de títulos**, do `<h1>` ao `<h6>`.

```html
<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Subtítulo do h2</h3>
<h4>Subtítulo do h3</h4>
<h5>Subtítulo do h4</h5>
<h6>Subtítulo do h5</h6>
```

### Hierarquia

```text
h1 → título principal
 └── h2 → seção
      └── h3 → subseção
           └── h4 → subseção
                └── h5
                     └── h6
```

### Exemplo

html
<h1>Desenvolvimento Web</h1>

<h2>HTML</h2>
<h3>Estrutura básica</h3>
<h3>Tags</h3>

<h2>CSS</h2>
<h3>Seletores</h3>
<h3>Flexbox</h3>


> **Importante:** a hierarquia deve representar a estrutura do conteúdo, e não apenas o tamanho visual do texto.
